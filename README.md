# akash-blackhat-2026-sigma-rules
5 production-tested Sigma rules for SIEM-based email threat detection. Black Hat USA 2026 — Detection Engineering Beyond the Inbox.

This repository contains 5 Sigma rules for SIEM-based email threat detection, released with the Black Hat USA 2026 talk:

**Detection Engineering Beyond the Inbox**

## Rules

* Display Name / Sender Mismatch
* Newly Registered Domain + Keywords
* Trusted Domain Authentication Failure
* Credential Harvesting Infrastructure
* Temporal Behavioral Anomalies

## Note

These rules are sanitized and use placeholder domains, fields, and values.

Review, tune, and validate each rule before using it in production.
